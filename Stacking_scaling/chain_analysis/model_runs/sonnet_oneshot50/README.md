# Claude Sonnet, one-shot, on the hard tier of `puzzles_50`

The same 45 hard levels as `../sonnet_hard50/` (15 per game), played on
2026-11-02 in the **one-shot** setting: the agent sees only the start images
(`obs_000_*`) and submits its whole plan once with
`python -m chain_analysis.play_cli plan <session> '<JSON list>'`.  The plan is
played through the real game rules with no observation in between, and the
session is then closed.  A rejected action is skipped (it still counts
toward the 40-action cap), so a plan whose last action is never reached as a
legal move does not verify at all.

One fresh Claude Sonnet subagent per level; the instruction files are in
`prompts/` (generated by `make_prompts.py`).  Seventeen agents were cut off
by an API rate limit; 14 of them had already sent their plan, the other 3
were resumed and sent theirs afterwards.

## Audit

Every agent transcript was checked: each agent read only its instruction file
and its own `obs_000_*.png` images, and ran exactly one command, the
`play_cli plan` call for its own session.  No agent read a level file, the
hidden state, source code or another session, and none ran Python.

## Results

| game | won | failed verify | never verified | rejected actions / episode | closed loop, won on the first verify |
|---|---|---|---|---|---|
| FluidNet | 15 / 15 | 0 | 0 | 0.0 | 13 / 15 |
| Domino | 12 / 15 | 0 | 3 | 1.3 | 13 / 15 |
| PipeFit | 10 / 15 | 5 | 0 | 0.8 | 11 / 15 |

"Never verified": a Domino plan whose patches were rejected
(`NoPhysicalSupport` on a step, `CellOccupied`), so not every patch was placed
and `submit_placement` and the push were refused.  The PipeFit losses
submitted a network that leaked or put a pipe on a portal's wall cell
(`EntranceExitOccupied`).

Per level, against the closed-loop run's first attempt:

| game | both win | one-shot only | closed loop only | neither |
|---|---|---|---|---|
| FluidNet | 13 | 2 | 0 | 0 |
| Domino | 11 | 1 | 2 | 1 |
| PipeFit | 8 | 2 | 3 | 2 |

17 of the 44 plans that reached the game equal the action list of the
closed-loop run's final episode on that level: in closed loop, Sonnet mostly
planned from the start image too and used the later images to catch slips.

## Caveats

* One run per level, one model.
* The one-shot score is close to the closed-loop first-verify score: the
  hard tier is hard for search, but its layouts can be read and planned from
  one image by Sonnet.  What still fails is reading cells: step heights in
  Domino, portal wall cells and supports in PipeFit.
